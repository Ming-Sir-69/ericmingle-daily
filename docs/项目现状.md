## 页面与内容链路

当前链路为 `entries/日期.json → scripts/build.js → public/`；日报中心按最新记录、近七天和更早记录展示。正式构建只读 `entries/`，示例构建另加入十二条 `entries-demo/` 数据。页面使用自带 SVG 风景，场景参数随星期、季节、天气和节日变化，模板版本保存在每条记录中。

`templates/current` 为 `v1`。本地真实构建生成两个 HTML，示例构建生成十四个 HTML；模板占位符全部填充，内部页面链接均存在，示例没有混入真实构建。浏览器已检查日报中心、周内记录展开、当天完整日报及返回中心。

本机测试使用 Node v26.7.0，Netlify 配置指定 Node 22。加密脚本语法检查通过，缺少 `BRIEF_PASSWORD` 时确实拒绝发布；StatiCrypt 安装、命令行参数兼容性、密码解锁和三十天记住功能仍待部署阶段实测。

首条日报中的新闻、账号、日历和 NAS 状态属于 Claude 提供的内容。本轮检查范围为源码、数据结构和本地页面展示，内容事实与采集新鲜度仍由内容链路核实。日报中心目前始终将最新一条记录标为“今天”，持续运行验收时需要检查断更后的日期显示。
